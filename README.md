# ITE 1100 – Tutorial #4: Git and GitHub

**Purpose of the Repository**

The purpose of this repository is to gain an understanding of functions in git and GitHub, such as creating repositories,
managing branches, committing files, pushing changes, and working with Pull Requests.

**Steps Followed to Complete the Tutorial**

The following steps were completed:
1. Installed Git on my computer and created a GitHub account.
2. Created a local Git repository.
3. Created a GitHub repository named `ITE1100-TUTORIAL4`.
4. Created a new branch called `tutorial-branch`.
5. Created a text file named `index.txt`.
6. Created a Python file named `myname.py`.
7. Committed changes to the repository.
8. Connected my local repository to GitHub and pushed the branch.
9. Created a Pull Request on GitHub.
10. Reviewed and merged the Pull Request into the `main` branch.
